
📊 Data Analytics Project(Customer Behavior Analysis)
📌Description
This project demonstrates an end-to-end data analytics workflow, including data loading, cleaning, SQL analysis, and building an interactive Power BI dashboard. The goal is to extract insights that support data-driven decision-making.

📁 Dataset
Source: Provided dataset (CSV/Excel)
Contents: Customer details, transactions, product information, and purchase behavior
Size: Varies based on source
Purpose: Used to perform EDA, SQL analysis, and visualization

🛠 Tools & Technologies
Python (Pandas, NumPy, Matplotlib/Seaborn)
SQL (PostgreSQL)
Power BI (Dashboard development)
Jupyter Notebook (Development environment)

🔍 Steps & Workflow
1. Data Loading (Python)
Imported the dataset using Pandas
Inspected structure, data types, and missing values

2. Exploratory Data Analysis (EDA)
Descriptive statistics
Distribution analysis
Trend and pattern detection
Outlier identification

3. Data Cleaning
Handled missing values
Fixed inconsistent formats
Removed duplicates
Created clean, analysis-ready datasets

4. SQL Analysis
Loaded cleaned data into PostgreSQL Server
Executed queries for:
  Customer segmentation
  Revenue and product analysis
  Discount impact
  Time-based purchase trends.

6. Power BI Dashboard
Built an interactive dashboard with:
Customer behavior trends
Discount analysis
Visual exploration of patterns

📈 Results & Insights
Identified customer behavior patterns
Highlighted top-performing products
Analyzed discount effectiveness
Revealed seasonal and demographic trends
Provided actionable recommendations for decision-makers

▶️ How to Run
Clone the repository
Open the Python notebooks and run them step-by-step
Load cleaned tables into your SQL database
Run SQL queries provided in the /sql folder
Open the Power BI file (.pbix) to view the dashboard
